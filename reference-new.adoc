= Was ist neu in Cloud Volumes ONTAP 9.19.1
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Cloud Volumes ONTAP 9.19.1 kann jetzt eingesetzt und ein Upgrade darauf durchgeführt werden. Die Basisversion dieses Release sowie die neuesten Patch-Versionen, die für Deployment und Upgrade verfügbar sind, sind in der NetApp Console einsehbar.

Weitere Informationen zu Cloud Volumes ONTAP Funktionen, unterstützten Konfigurationen, Limits und mehr sind unter  https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/whats-new.html["Cloud Volumes ONTAP Dokumentation"^] zu finden.



[[9-19-1-ga]]
== 9.19.1 GA

Die Cloud Volumes ONTAP 9.19.1 General Availability (GA) Version ist jetzt für Deployment und Upgrade in Amazon Web Services (AWS), Microsoft Azure (Azure) und Google Cloud verfügbar.



[[upgrade-notes]]
== Upgrade-Hinweise

Lesen Sie diese Hinweise, um mehr über das Upgrade auf diese Version zu erfahren.



[[how-to-upgrade]]
=== Upgrade-Tipps

Upgrades von Cloud Volumes ONTAP müssen über die Konsole durchgeführt werden. Sie sollten Cloud Volumes ONTAP nicht mithilfe von System Manager oder der CLI aktualisieren. Dies kann die Systemstabilität beeinträchtigen.

https://docs.netapp.com/us-en/storage-management-cloud-volumes-ontap/task-updating-ontap-cloud.html["Erfahren Sie, wie Sie ein Upgrade durchführen, wenn die Konsole Sie benachrichtigt"^].



[[supported-upgrade-path]]
=== Unterstützter Upgrade-Pfad

Sie können Cloud Volumes ONTAP in AWS, Azure und Google Cloud von 9.18.1 auf 9.19.1 aktualisieren. Die Console fordert Sie auf, geeignete Cloud Volumes ONTAP Systeme auf diese Version zu aktualisieren.



[[downtime]]
=== Ausfallzeit

* Das Upgrade eines Einzelknotensystems nimmt das System für bis zu 25 Minuten offline, währenddessen werden die I/O-Vorgänge unterbrochen.
* Das Upgrade eines HA-Paars ist unterbrechungsfrei und die I/O-Vorgänge werden unterbrechungsfrei durchgeführt. Bei diesem unterbrechungsfreien Upgrade-Prozess wird jeder Node parallel aktualisiert, um weiterhin I/O für Clients zu ermöglichen.
